# Ответы на контрольные вопросы

**1. Каковы основные шаги для создания приложения с подключением к базе данных в WPF?**
Создать и заполнить базу данных в SQL Server; создать проект «Приложение WPF (.NET Framework)»;
подключить сборку System.Configuration; добавить строку подключения в App.config; разработать интерфейс в XAML;
в коде открыть соединение (SqlConnection), выполнить команды (SqlCommand) и вывести результаты в элементы управления;
добавить обработку исключений и протестировать приложение.

**2. Какие способы подключения к базе данных можно использовать в технологии ADO.NET?**
Строка подключения в файле App.config (раздел connectionStrings) или прямо в коде; построение строки через
SqlConnectionStringBuilder. Проверка подлинности Windows (Integrated Security=True) или SQL Server
(User ID и Password). Разные поставщики данных: SqlClient (SQL Server), OleDb, Odbc, OracleClient.

**3. Что такое библиотека ADO.NET и какие основные компоненты она содержит?**
ADO.NET — набор классов .NET для работы с источниками данных. Подключённый уровень: Connection (соединение),
Command (команда SQL), DataReader (быстрое чтение результата), Parameter (параметры запроса), Transaction (транзакция).
Отключённый уровень: DataSet, DataTable, DataRow, DataView и DataAdapter, который переносит данные между базой и DataSet.

**4. Какие типы запросов на выборку данных можно использовать при работе с базой данных в WPF?**
Простые SELECT, запросы с условием WHERE, сортировкой ORDER BY, группировкой GROUP BY и агрегатными функциями
(COUNT, SUM), соединения таблиц JOIN, вложенные подзапросы, обращения к представлениям и хранимым процедурам.
Выполняются через ExecuteReader (много строк), ExecuteScalar (одно значение) или SqlDataAdapter.Fill.

**5. Какие инструменты технологии ADO.NET используются для выполнения запросов модификации данных?**
SqlCommand с методом ExecuteNonQuery для INSERT, UPDATE, DELETE; параметры SqlParameter;
SqlTransaction для объединения нескольких изменений; SqlDataAdapter.Update для переноса изменений из DataTable в базу.

**6. Какие основные элементы XAML-разметки используются при создании приложений WPF с подключением к базе данных?**
Window, контейнеры Grid, StackPanel, DockPanel, GroupBox; для вывода данных DataGrid, ListBox, ComboBox;
для ввода TextBox, DatePicker; Button для действий; привязка данных {Binding} и свойство ItemsSource.

**7. Как осуществляется обработка событий, связанных с базой данных, в приложениях WPF?**
В XAML элементу назначается обработчик события (Click, Loaded, SelectionChanged, MouseDoubleClick), а в коде
этого обработчика выполняются запросы к базе и обновляются элементы окна. Ошибки перехватываются в try/catch.
В этой работе: Loaded — загрузка складов, Click — чтение файла и приём товара, SelectionChanged — содержимое склада.

**8. Какие способы обеспечения безопасности данных можно использовать при работе с базой данных в приложениях WPF?**
Параметризованные запросы вместо склейки строк (защита от SQL-инъекций); проверка подлинности Windows;
минимальные права пользователя базы; ограничения целостности (ключи, CHECK, триггеры); транзакции;
хранение строки подключения в конфигурации и её шифрование; проверка введённых данных.

**9. Какие подходы следует выбирать при создании приложений WPF с базой данных для обеспечения хорошей производительности?**
Выбирать только нужные столбцы и строки; считать итоги на сервере (агрегаты, представления) вместо циклов в программе;
открывать соединение как можно позже и закрывать сразу (using, пул соединений); использовать DataReader для чтения;
индексы по полям поиска; длительные операции выполнять асинхронно, чтобы окно не зависало.

**10. Каким образом можно провести отладку и тестирование приложения WPF с базой данных?**
Точки останова и пошаговое выполнение в Visual Studio (F9, F10, F11); просмотр значений переменных и текста запросов;
проверка запросов отдельно в SSMS; тестовые наборы данных для обычных и граничных случаев
(здесь — четыре тестовых файла накладных); проверка сообщений об ошибках; модульные тесты.
